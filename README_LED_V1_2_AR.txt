ELYAS LIGHT CONTROL - Android V1.2 - LED independent output
==========================================================
تحديث مبني على Android V1.1 Maroon الناجح.
- تمت إضافة زر LED مستقل داخل صفحة الإنارة الرئيسية بجانب زر السكن.
- أمر البلوتوث الجديد LED ON و LED OFF؛ حالة الزر تؤخذ من STATE BITS (bit 6).
- لا يتطلب تغيير عنوان البلوتوث ELYAS-LIGHT أو رمز الشاشة 462913.
- رمز أول تشغيل للتطبيق 223232 يبقى كما كان. الاحتفاظ ببيانات التطبيق عند تحديث APK بنفس معرف الحزمة يحتفظ بالقفل.
- أضيف شعار ABU ZAHRA الأصلي الذي أرسله المستخدم وDodge Ram صورة صغيرة أسفل صفحة التحكم.
- إضافة مسافة علوية للأجهزة الحديثة حتى لا تتداخل واجهة التطبيق مع شريط النظام.

مهم: زر LED لن يعمل مع كود الشاشة V1.6 أو المستقبل V1.5 القديمة؛ يلزم تحديثهما بكود V1.7 المرفق في حزمة ESP32 المنفصلة.

للرفع على GitHub:
1- فك ضغط هذا ZIP على الكمبيوتر.
2- ارفع محتويات هذا الملف إلى جذر مستودع GitHub واستبدل الملفات السابقة (أو ارفع تغييرات التطبيق فقط).
3- تحقق من وجود ملف .github/workflows/build-apk.yml داخل .github/workflows وليس في workflows بالجذر.
4- نفذ Commit ثم افتح Actions / Build Android APK واتبع نتيجة التشغيل.
5- تجد ملف APK في Artifacts بعد نجاح بناء GitHub. هذه الحزمة كود المصدر وليست APK مبنياً.

لا تغيّر أسماء المجلدات الرئيسية app و .github وأسماء ملفات Gradle.
